# Mathpix-Ready Staging (Run 3)

Verified copies of the 22 approved segment PNGs plus the Stage 3 assembled PDF, staged for
the optional Mathpix alternate path (Stage 4). Not pursued further in this run — the primary
deliverable is the direct LaTeX compilation path (Stage 5).

## Verification against Mathpix input requirements
- **Format:** all 22 files are PNG (RGB, 8-bit, non-interlaced); the assembled file is PDF 1.4.
- **Resolution:** every PNG is 1700px wide (200dpi render of a letter-size page) — well above
  Mathpix's minimum recommended resolution for legible handwritten math.
- **File size:** all PNGs are 74KB–175KB, comfortably under Mathpix's per-image size limits.
  The assembled 22-page PDF is 3.7MB.
- **Page count/order:** PDF preserves `page01_seg01` ... `page04_seg06` reading order,
  one segment per page.
